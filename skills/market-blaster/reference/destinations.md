# Destination reference

## devto
Tutorial with code, context, tradeoffs and relevant tags. Title required, maximum 128 characters.

## hashnode
Technical article with an example and context. Title required, maximum 250 characters.

## gist
Only a runnable example grounded in the brief, with minimal instructions. Title required; otherwise write a skip file with a reason.

## bluesky
Concrete hook plus code or before/after; one link. Maximum 300 graphemes.

## mastodon
Conversational post with CamelCase hashtags and a content warning only when needed. Default 500 characters; `mastodon.maxChars` sets the instance limit (hachyderm.io: 2263). The actual limit is verified at publish preflight.

## linkedin
Outcome in the first two lines, link at the end, at most three hashtags. Avoid 'excited to announce'. Maximum 3000 characters.

## x
Concrete hook plus code or before/after; one link. Maximum 280 weighted characters.

## hn
No AI-written text or draft. The human submits the canonical article.

## reddit
Bullet talking points only, with suggested subreddit fit and a self-promotion disclosure reminder. The human checks rules and writes the post. Title required, maximum 300 characters.

## threads
Conversational standalone post, maximum 500 characters.

## medium
Readable technical article; import the canonical URL where possible.

## producthunt
Bullet talking points only, with a self-promotion disclosure reminder. The human writes the launch text.

## substack
Reader-focused newsletter note with technical substance. Title required.
